# 回归训练闭环：正确的梯度不等于可靠的实验

问题：在尺度不同的三个连续特征上拟合带噪声的线性关系，验证自动微分能否支持真实参数更新。
数据是明确标注的合成任务 `y=2x₁−x₂+0.5x₃+0.7+ε`，ε~N(0,0.2²)；
它让真实参数与噪声水平已知，适合作为机制验证，不代表真实业务数据上的效果。

目标 L=mean((XW+b−y)²)，完整批次梯度下降更新 W←W−η∇W、b←b−η∇b。
用中心差分检验训练损失梯度；用 NumPy `lstsq` 独立求最小二乘解。
`lstsq` 是数值参考，不以显式逆矩阵求解，避免把病态 XᵀX 的误差当作自动微分错误。

先固定 320/96/96 训练/验证/测试划分，标准化参数仅从训练集估计。
所有 300 次更新只使用训练标签，最优检查点按验证 MSE 选择；最后计算测试指标。
最终迭代参数用于对照 OLS，验证选择的检查点用于实际效果，二者含义必须区分。

对照一：训练均值预测，衡量学到关系相对常数模型的收益。对照二：同一训练集上的 OLS，
区分优化误差与噪声/泛化误差。消融：原尺度下使用相同学习率和迭代预算，检查标准化的作用。
H=2AᵀA/n，A 含偏置列；梯度下降要求 0<η<2/λmax(H)。记录两种尺度的稳定学习率上界，
原尺度发散在训练 MSE 超过配置阈值时停止，不隐藏为非有限 JSON，也不把它记成主实验失败。

失效案例：测试标签整体加 5，模型保持原预测。偏置漂移会显著增加误差，说明同分布假设的边界；
这是人工压力测试，不能称为自然 OOD 基准。较小学习率可避免原尺度发散，
此消融不证明“不标准化就无法学习”，也不是公平调参后的最优方法比较。

运行：`uv run --locked python -m kaleido.demos.linear_regression`。
产物含完整数据与划分、数据哈希、训练曲线、选中参数、逐样本预测、指标、耗时和环境来源。
时间戳/路径/耗时每次不同；同机锁定环境下数值可复现，跨 BLAS/平台允许浮点容差。
单 seed 主报告只说明实现与控制实验；其他 seed 的 OLS 收敛测试不等价于多 seed 泛化结论。
