# P4可验证任务：隔离结构，拒绝宽松奖励

任务为小整数多步表达式的最小非负余数。训练4种AST结构，验证/测试各2种未见结构；
固定seed和表达式hash，默认128/32/32题，完整操作数、标签与题族都归档。
表达式解释器只允许整数加减乘模，不调用eval或执行生成代码。
题族虽按AST结构隔离，但代数等价和基础运算仍重叠，不将其冒称全新技能泛化。

训练标签由AST求值；训练奖励用独立的字符串边界/ASCII数字解析。
最终评测使用regex fullmatch和展开多项式oracle，不信任保存的训练标签，也不调用训练解释器。
只有整条回答符合 `<answer>N</answer>`、数值正确且非截断才奖励1。
重复答案、附加说明、前导零、代码与超长数字均不给奖；允许外侧空白。
宽松数值正确率只用于诊断格式收益，不能当训练奖励。

报告严格准确率、数值正确率、格式率、截断率、逐题结果和Wilson区间。
32题区间较宽，不能把几个样本的变化解读为普遍收益；另列训练多数答案基线防止常数策略掩盖问题。
完整测试：`uv run --locked --all-extras pytest tests/test_posttrain_tasks.py`。
