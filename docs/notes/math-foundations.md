# P0 最小数学地基

这里建立主线立即使用的数学联系，其余推导随算法补齐。

**线性代数**：X∈Rⁿˣᵈ 把 d 维参数映射为 n 个预测，偏置可并入全 1 列。
最小二乘的一阶条件是 Aᵀ(Aθ−y)=0；满列秩时解唯一，秩亏时可有多个解，
`lstsq` 选择最小范数解。显式求逆不是实现要求，分解求解通常更合适。
反传中线性映射的伴随是转置：对 AX 的 VJP 是 AᵀG。

**微积分与优化**：MSE 梯度为 2Aᵀ(Aθ−y)/n，Hessian 为 2AᵀA/n。
沿 Hessian 特征向量方向，误差每步乘以 1−ηλ，所以稳定要求 |1−ηλ|<1。
大尺度特征使最大特征值变大，允许的步长缩小；标准化改变条件数与步长范围，
不改变含偏置的无正则线性模型可表达的预测空间。重复出现的图节点梯度相加，是多路径链式法则。

**概率**：若 y|x~N(xᵀw+b,σ²) 且噪声独立同方差，负对数似然
是常数+n·MSE/(2σ²)，因此最小二乘对应高斯最大似然。若噪声重尾、异方差、关系非线性，
该解释的假设可能失效；高斯噪声下预期误差的自然量级是 σ²，有限样本误差不必正好等于它。

**信息论**：离散交叉熵 H(p,q)=−Σp log q，熵 H(p)=−Σp log p，
二者差为 KL(p‖q)≥0（q 在 p 的支持上为正）。分类负对数似然是单样本交叉熵；
语言建模平均 token NLL 的 exp 是困惑度，必须注明 tokenizer、token 数和边界处理后才能比较。
P0 不据此声称完成分类或语言模型评测，稳定 logsumexp 与相应实验在后续模块实现。

**证据**：`tests/test_tensor.py` 的解析回归梯度与中心差分，
`tests/test_linear_demo.py` 的 OLS 对照，以及回归 demo 中的谱半径学习率边界，
把上述矩阵、概率与优化联系到实际运行。数学广度不作为进入后续主线的前置门槛。
