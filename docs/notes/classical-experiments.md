# P1 对照协议

目的：检查六类手写估计器在真实小数据上是否符合数学定义和成熟实现。
不以某次准确率高于参考证明算法更好；对齐目标和初始化优先于比较成绩。

三个数据集均来自固定 sklearn 版本内置文件，运行不下载数据：
Diabetes 的原始未缩放 10 个特征做回归；Breast Cancer 做二分类；Iris 做分类、降维和聚类。
记录数据来源、特征名、完整 X/y、内容哈希与样本 ID。

seed=42/7/2026 各自进行约 60/20/20 划分，分类分层。
StandardScaler 只在训练集拟合，参考 scaler 也只见训练数据。
逻辑回归 λ∈{0.001,0.01,0.1} 以验证 NLL 选择；树深度∈{1,2,3,5,8} 以验证准确率选择，
同分取较浅者；EM 分量数∈{1,2,3,4} 以验证平均 log likelihood 选择。
PCA 预先固定 2 维、K-means 固定 3 簇，不以测试标签选择它们。
ARI 只在最后报告阶段使用真实类别，不参与优化、初始化或选参。

参考比较：

- 线性回归使用同样的训练变换和偏置；逻辑回归精确换算 C=1/(nλ)。
- 树匹配深度与 min_samples_leaf；同分选择和内部精度不保证树结构相同。
- PCA 比较投影矩阵和重建；K-means 提供相同初始中心。
- EM 提供相同权重、均值和对角方差。手写版本记录 M 步后的似然，sklearn 停止判断使用
  当轮 M 步前 E 步的似然，可能多做一次更新。因此默认两者用 1e-10 容差，报告实际逐样本差。
- 无监督参考从手写模型选中重启的初始状态开始，是正确性对照，不是各自默认初始化的性能赛跑。

运行：`uv run --locked --extra reference python -m kaleido.demos.classical_ml`。
每次独立目录保存 data/metrics/summary/selection/models/predictions/histories/checks/failure_cases/cost
与 manifest。配置在 `configs/p1_classical.json`，基础包仍只依赖 NumPy。

样本标准差描述三个有重叠数据的划分之间的变化，不是独立重复试验的置信区间。
没有嵌套交叉验证，也没有大规模搜索；已查看过的测试集不能继续用于调参。
人工反例展示 XOR 表达能力、PCA 丢失低方差信号、对角协方差遗漏相关性，
不把这些反例称为自然分布外测试集。

阶段测试还从归档逐样本输出复算指标、检查划分互斥、训练均值来源、验证选择及重跑一致性。
最终数字与完整记录见 `results/p1/REPORT.md`。
