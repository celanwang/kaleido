# 最终交付的完整性边界

统一校验入口覆盖 configs、data、P0–P6 全部历史证据与依赖文件，P6 的导出图和重训差异不能遗漏。
维护者经审查更新清单，运行时只读验证；目录中新增但未入清单的工件也会失败。
历史运行的“140文件”记录保持原样，本轮扩展到163文件，不回写历史证据。

配置在执行前读取一次，原始 bytes 和摘要随单阶段 run 保存为 configuration.json、receipt.json。
运行过程中源配置被编辑时，记录 changed 标记；回执仍指向实际执行的原始输入，不能重新读文件
后把新摘要冒充旧输入。复跑父进程还核对分配目录、持久回执、manifest 和配置快照，不只相信零退出码。

原生 Qwen 的配置、generation config、tokenizer、词表/merges、许可和权重均有固定 SHA256。
revision 名称与权重摘要不能替代 tokenizer 文件摘要，加载本地快照时先校验全部文件再构造模型。
本轮只是固定已发布 revision 的既有 bytes，没有更换模型、模板或训练算法。

部署 manifest 解析拒绝重复键、非对象与非有限数字。运行协议、维度、验证状态须满足格式，
声明的 context/vocab 必须与计算图 embedding 维度一致。损坏元数据须返回明确错误，不能等首次推理才失败。
这些机制证明相对于审查清单的一致性，不构成外部数字签名或任意第三方模型的安全加载承诺。
