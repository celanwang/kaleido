# Kaleido v1.0.0

发布范围为 P0–P6 的可复现研究主线，包含原理实现、正式实验、真实负结果与可独立运行的 P3 CPU 推理工件。

源码 checkout 使用 `uv sync --locked --all-extras`，随后执行：

```sh
kaleido doctor
kaleido verify --deep
kaleido reproduce --profile smoke
kaleido reproduce --profile formal
```

smoke 为接线检查，P4/P5 使用随机 fixture；formal 按原预算重训 P3/P4，需要固定 Qwen 缓存。
P5 重评发布的冻结工件，不自动消费同轮新训练结果。完整证据与限制见各阶段 `results/pN/REPORT.md`。

wheel 仅包含代码。推理消费者安装 wheel 及锁定的 CPU PyTorch 运行时，并解压发布的 Decoder bundle：

```sh
kaleido predict --bundle decoder-42
```

stdin/stdout 为 JSON-lines，例如 `{"prompt":"Alice was","max_new_tokens":12}`。
无需 checkout、语料或 Qwen 权重；CPU、batch1、完整裁窗 greedy，未导出 KV cache。
`.pt2` 只验证 PyTorch 2.14.1；跨版本、跨框架与加速器部署不在本次承诺内。

GRPO 的稳定迁移收益仍未获得本项目证据支持，Judge 校准一致率仅50%，已关闭其模型排名。
本版本不宣称完成所有可选算法或达到通用语言模型能力。第三方数据/模型许可声明保留在源码相应目录，
完整 Qwen 基座不随包发布。

发布流程只允许从 main 手动启动，重新运行校验、测试、smoke、导出及独立 wheel 推理，再生成 GitHub draft release。
合并功能 PR 与真正公开发布是两个独立事件；draft 需维护者审阅后发布，不自动推送到 PyPI。
