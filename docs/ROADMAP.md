## 边界

- 自研 core 使用 NumPy/CPU/float64，服务于理解与小模型。支持 MLP 和选定注意力后暂时冻结。
  P3 规模训练采用成熟框架，关键结构、目标函数和训练循环显式实现；通过数值对照联系两层。
- 小模型从零预训练与 Qwen 后训练是两条路径；前者解释训练机制，后者比较已有模型的更新方法。
- 评测、数据隔离和实验记录从 P0 开始，P5/P6 是整合阶段。
- 模型大小、语料 token 预算由本机资源探测决定。当前不预设未经测量的吞吐或训练周期。
- GRPO 先用可判定的数值/符号任务；代码执行须先实现独立隔离方案，不把宿主进程当沙箱。
- 降级可减少模型/算法/任务规模；正确性验证、独立测试、完整记录不降级。

## 模块工作约定

每个模块交付运行代码、一页原理与取舍笔记、可复现 demo；提交前通过相关测试、lint 与真实运行。
提交使用 `feat(scope): ...` / `docs: ...`，正文包含行为、证据和限制，参照
[mathspeak 提交历史](https://github.com/celanwang/mathspeak/commits/main/)。每个完成模块单独提交并推送，
阶段末汇总结果；不把 smoke test 当作阶段完成。

P0 分三模块：实验协议 → 自动微分 → 回归训练闭环。后续从 P1 代表性算法继续，
每阶段以验收结果决定下一步，不把本文当作已完成的功能列表。
